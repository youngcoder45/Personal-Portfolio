After too many years of tiling-WM config tangles, the "minimal niri" config
became my daily driver. `New-Niri-minimal-dots` is exactly that: the dotfiles I
actually run, versioned so I can rebuild a fresh Arch install in minutes.

The whole thing is opinionated: **one config file, no bloat, sane defaults.**

```lua
# niri config, the tl;dr
spawn-at-startup "waybar"
spawn-at-startup "nm-applet"
input {
    keyboard {
        xkb {
            rules "evdev"
            layout "us,us"
        }
    }
}
```

## Philosophy

- If a setting is confusing, remove it instead of documenting it.
- Monospace everything. DejaVu when the mood strikes.
- Kanshi for monitor changes, custom keybinds for window management.
- Updates come as PRs; the config is a living document.

## Things nails

- Fuzzy-lens look without compositor heavy lifting.
- A workspace model that doesn't beg for attention.
- Fast enough that I keep forgetting the WM is "rice".

The repo also ships an install script so cloning + running is enough to go from
vanilla Arch to my exact desktop.
